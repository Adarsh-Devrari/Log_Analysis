# Log_Analysis
# Log Analysis & SIEM Dashboard

A Python-based log analysis and SIEM dashboard for monitoring,
analyzing, and visualizing system logs.

## Features

- Log parsing
- Log level analysis
- Error and warning detection
- Security event detection
- Interactive SIEM dashboard
- Log visualization using charts

## Technologies

- Python
- Streamlit
- Pandas
- Plotly
